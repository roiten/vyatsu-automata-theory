# Вёдра

Учебное WPF-приложение на C# для .NET Framework 4.7.2.

## Запуск

1. Откройте `Buckets.slnx` в Visual Studio на Windows.
2. Восстановление сторонних пакетов не требуется.
3. Соберите проект и запустите `Buckets`.

## Возможности

- Автоматическое заполнение десяти вёдер с интервалом `y = -0.035 * u + 3.6` секунд.
- Аварийное удаление активного ведра с заполнением от 1 до 9 литров с вероятностью 0–100%.
- Возврат удалённых вёдер пустыми на следующем такте.
- Уникальные цвета из `resources/pictures/bucket/half/` и `full/`.
- Настройка цвета и заполнения, случайная генерация, сброс.
- Открытие и сохранение конфигурации INI.
- Проверка числового ввода и сообщения об ошибках.

## Формат INI

```ini
[colors]
bucket0 = black.png
bucket1 = blue.png

[fullness]
bucket0 = 0
bucket1 = 5
```

Конфигурация должна содержать десять уникальных цветов. Заполнение каждого ведра задаётся целым числом от 0 до 10.

## Структура

- `Bucket.cs` — модель ведра.
- `BucketController.cs` — такты автомата, генерация воды и аварийная лампа.
- `IniConfigService.cs` — чтение и запись INI.
- `MainWindow.xaml(.cs)` — основное окно и игровой цикл.
- `ColorSettingsWindow.xaml(.cs)` — настройка цветов.
- `BucketFillLevelSettingsWindow.xaml(.cs)` — настройка заполнения.

Примечание: проект рассчитан на Windows/WPF. В текущем окружении отсутствуют MSBuild и WPF reference assemblies, поэтому сборку следует проверить в Visual Studio.
